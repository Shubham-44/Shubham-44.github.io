# Shubham K. Darkad — Portfolio

A responsive, buildless portfolio focused on recent work and website services.

Run `npm run dev` and open http://localhost:5173. Run `npm run check` to check JavaScript syntax.

- `dist/index.html`: personal details, services, project cards, and contact copy.
- `dist/style.css`: responsive design and colour tokens.
- `dist/script.js`: project details and accessible native dialog interaction.
- `dist/assets/`: project imagery copied from the local PETER BOX, PU LINE SOLUTION, and ICY JEWELS projects.

The contact section links to shubhamdarkad17@gmail.com using a mailto link. Project summaries accurately distinguish frontend previews from live commerce. Project card compositions are adapted portfolio visuals, not screenshots.

## GitHub Pages

The GitHub Actions workflow in `.github/workflows/pages.yml` publishes `dist/` when changes are pushed to `main`. In the repository's **Settings → Pages**, the source is **GitHub Actions**.
